# Multi Page Website 2

A responsive **multi-page website** built with a clean and modern interface. The project demonstrates structured web pages, smooth navigation, and responsive layouts across different screen sizes.

## 🌐 Live Demo

**[View Live Website](https://gokul-dev2004.github.io/multi-page2/)**

## ✨ Features

* 📄 Multiple interconnected pages
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* 🧭 Simple and intuitive navigation
* 🖥️ Mobile, tablet, and desktop friendly
* ⚡ Lightweight and fast-loading
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Git & GitHub
* GitHub Pages

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Gokul-Dev2004/multi-page2.git
```

### 2. Navigate to the project folder

```bash
cd multi-page2
```

### 3. Open the project

Open `index.html` in your browser to view the website locally.
